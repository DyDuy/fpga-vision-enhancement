# Verification

- `testplan.md`: truy từ yêu cầu sang phép kiểm tra.
- `tb/unit/`: kiểm tra module riêng.
- `tb/integration/`: kiểm tra pipeline.
- `checkers/`: so sánh với model.
- `assertions/`: giao thức và bất biến.
- `vectors/generators/`: sinh dữ liệu.
- `vectors/golden/`: vector chuẩn nhỏ được commit.
- `regressions/`: cấu hình test; log tự sinh đi vào `build/`.
